# GZ MES 界面设计规范（v0.1）

来源：Stitch 设计稿两份（工作台、生产批次查询+批次详情抽屉）共用同一套 DESIGN.md，本文是其落地到 Ant Design Vue 的裁剪版。
登录页为例外（4 种 aurora 系深色风格，见 `frontend/src/views/login/`），登录后的全部页面遵循本文。

## 1. 基调

- 工业企业级、高密度、低噪音。"深蓝控制台外壳 + 浅灰工作区"。
- 一切颜色/圆角/字号走 `frontend/src/theme.ts` 的 token 与 CSS 变量，页面里不写死颜色。

## 2. Token（theme.ts）

| 项 | 值 |

## 3. 应用外壳（BasicLayout）

```
┌────────┬──────────────────────────────────────────────────────┐
│ Logo   │ ☰  面包屑          [厂区切换▾] [🔍搜索项目/批次/QR]  班次·节拍  🔔 ? ⛶  用户▾ │
│ 菜单   ├──────────────────────────────────────────────────────┤
│ (浅色) │  画布 #F5F7FA，padding 16，内容由页面自行分卡片        │
│        │                                                      │
│ 收起   │                                                      │
└────────┴──────────────────────────────────────────────────────┘
```

- 顶栏高 56，白底，底边 `#F0F0F0`。左：折叠按钮 + 面包屑（一级菜单 / 当前页）。中：厂区选择器（admin 可切，外协账号只读显示本厂）、全局搜索框（占位"搜索项目 / 批次 / QR…"）。右：班次/节拍小卡（演示用静态）、通知铃（红点）、帮助、全屏、用户下拉（头像首字 + 姓名(角色)）。
- 演示环境橙色标签保留在顶栏。
- 内容区不再统一包白底：页面自己决定卡片划分（列表页=筛选卡 + 表格卡）。
- 响应式：<1200 侧栏自动折叠；<768 侧栏变抽屉，顶栏只留折叠/标题/用户。

## 4. 页面模板

### 4.1 工作台（首页 `/`）

从上到下：
1. **标题条卡**：状态点 + "铝单板生产执行看板"，右侧 Tag：生产中 N 个批次 / 达成率；操作按钮：一键扫码报工（主）、新建生产批次、打印标签(QR)、导出日报。
2. **KPI 四卡**（`a-row` 24 栅格，各 6）：今日计划投产(件 / m²)、钣金加工进度(件已下线 / %)、喷涂完工(件 / m²)、成品装架与待发(件 / 架)。卡内：标题 + 右上圆形色底图标；大数 28 粗 + 单位；底部分隔线后一行次级指标（较昨日、合格率等）。
3. **11 工序流转看板**：一行 11 个小卡（可横向滚动），每卡：序号+工序名、大数、底部状态 Tag。当前有堆积/质检卡用对应语义色描边。右上图例：在制运转 / 工序堆积 / 质检完成。
4. **下半区 16 : 8**
   - 左：在制批次表（Tab：全部 / 钣金工段 / 喷涂工段 / 包装发货 / 加急●）。列：批次编号(链接, mono) / 工程项目(两行：名 + 板块代号) / 规格材质(两行) / 件数·展开面积(右对齐) / 当前工序 Tag / 责任班组 / 完工进度(进度条+文字) / 质检状态 Tag / 操作(明细·交接)。
   - 右：异常预警卡（列表项按语义色浅底：现场催单(红)、质检偏差(黄)、交接缺件(灰)），底部"查看全部预警"；其下"今日装车发货计划"卡。

### 4.2 列表页（通用，如生产批次查询 `/scheduling/batches`）

1. **筛选卡**：`a-form` inline，字段 2–4 行栅格对齐，右侧 查询 / 重置 / 展开更多。已选条件用可关闭 Tag 显示在表格工具栏左侧。
2. **表格卡**：
   - 工具栏：左主按钮（新建生产批次）+ 次按钮（批量审核、导入清单、导出▾）；右：列设置、密度、刷新。
   - 表格：`size="middle"`，表头 `#FAFAFA` 600 字重；行高 44；数量/面积右对齐 `tabular-nums`；编号列 mono + 可复制；可勾选；支持 `expandable` 展开"构件展开明细表"子表。
   - 汇总行（`summary`）：当前筛选 N 个批次 / 总件数 / 总展开面积 / 总计价面积 / 生产中·已完工·加急逾期 计数 / 数据更新时间。
   - 分页：右下，每页 20/50/100，跳页。
   - 状态：加载骨架屏；空态图标 + "暂无匹配的生产批次数据" + 重置按钮。
3. **详情用抽屉**（右侧 `a-drawer` 宽 720，不跳页）。

### 4.3 详情抽屉（批次详情）

- 头：标题"批次详情: PC-xxx" + 状态 Tag（生产中/逾期加急）。
- Tab：基本信息 / 11 道工序全景● / 一物一码构件清单(N) / 质检记录(QC) / 发货物流。
- 基本信息页：
  1. 追溯条码卡（灰底）：UID 等宽大号 + 派工时间/责任班组 + 右侧 QR 占位 "扫码报工"。
  2. 工程要素 `a-descriptions` 2 列：所属项目、安装标段、材质厚度、涂层体系、颜色色号、排产件数、展开面积、计价面积、计划开工、最迟交付(逾期红)。
  3. 工序进度：垂直 `a-timeline`（完成=蓝勾、当前=脉冲点+浅蓝底块、待办=灰号），每项：工序名 + 时间 / 机台·报工人·完成数；后序折叠成一行箭头文字。
  4. 异常与调度备注：warning 浅黄块。
- 底部固定操作栏：左"操作员: xxx"，右 打印批次流转卡 / 生成件标签 / 去工位报工(主)。

## 5. 通用组件（`frontend/src/components/`）

| 组件 | 用途 |
|---|---|
| `PageCard` | 白卡：title / extra / 内容，统一边框阴影 |

| `ProcessTimeline` | 工序垂直时间线 |
| `CodeText` | 等宽编号 + 复制按钮 |
| `FilterCard` | 列表页筛选表单容器（查询/重置/展开） |
| `TableToolbar` | 表格工具栏 |

## 6. 11 道工序（演示口径）

01 开料 → 02 折弯 → 03 钣金下线 → 04 钣金质检 → 05 喷涂接收 → 06 上挂喷涂 → 07 下挂冷却 → 08 喷涂质检 → 09 成品接收 → 10 成品装架 → 11 发货对账

后端 `job` 表以线上 8 工序为准，前端展示按上表映射；无扫描数据的工序显示"—"。
